# UI & UX Design Rule

Whenever creating, editing, or building UI/UX components, pages, or layout styles in this workspace:

1. **Mandatory Design Reference**: Always read and strictly adhere to the design system guidelines defined in [`Frontend/design.md`](file:///c:/Users/pruth/OneDrive/Desktop/vscodes/RICE%20agent/Frontend/design.md).
2. **Tactile Precision Dark System**:
   - **Colors**: Base surface `#1a1c1e`, primary accent `#2dd4bf` (Emerald), text `#e2e2e6` / `#c4c7cc`.
   - **Depth & Shadows**: Use dual-layered light (-5px -5px, rgba(255,255,255,0.05)) and dark (5px 5px, rgba(0,0,0,0.5)) offsets for extruded (raised) vs inset (sunken) tactile feel.
   - **Component Patterns**: Buttons default to raised and active to sunken. Input fields are always sunken.
